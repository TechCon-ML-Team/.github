<h2 align="center">О компании</h2>

[TechCon](https://techcon.ru) разрабатывает платформу цифрового обследования зданий и сооружений.
Технические обследования с помощью наших инструментов обходятся в **3 раза дешевле** и выполняются в **4 раза быстрее** рыночного стандарта.

За 5 лет работы платформа применена на **20 000+ объектах**.

---

<h2 align="center">Что мы разрабатываем</h2>

Собственный стек ML-инструментов для цифрового обследования:

- Распознавание паспортов оборудования — PDF и фото в структурированные данные
- Классификация дефектов по голосовым записям — полевые обходы без бумаги
- Визуальная дефектоскопия — автоматическое выявление дефектов по фото
- Поиск технических планов — атрибутный поиск по базе зданий
