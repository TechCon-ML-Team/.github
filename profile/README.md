<h2 align="center">TechCon ML Team</h2>

Мы — инженерная команда внутри [TechCon](https://techcon.ru), которая проектирует, разрабатывает и сопровождает прикладные ML-сервисы для технических обследований зданий, инженерной документации и полевых сценариев.

Мы ведём полный цикл сами:
- прикладные исследования и прототипирование;
- модели, API и асинхронные очереди;
- облачную инфраструктуру и эксплуатацию;
- наблюдаемость, алерты и рабочие регламенты;
- продуктовые демонстрации и интеграционные контуры.

---

<h2 align="center">Основные направления</h2>

| Направление | Что решаем | Что получает пользователь |
|---|---|---|
| Голосовые сценарии для дефектов | Распознаём полевую речь и превращаем её в структурированные результаты | Быстрый ввод без бумажных бланков |
| Визуальная дефектоскопия | Анализируем фотографии строительных дефектов | Более быстрый первичный разбор материалов |
| Документы и отчёты | Проверяем инженерные таблицы, отчёты и технические формы | Понятные ошибки, подсветка нарушений, объяснимые проверки |
| Технические данные и поиск | Извлекаем поля и строим поиск по инженерным данным | Быстрый доступ к нужной информации |
| Платформа и эксплуатация | Держим единый инфраструктурный и наблюдаемый контур | Прозрачная эксплуатация и контролируемые релизы |

---

<h2 align="center">Как читать эту организацию</h2>

Если вы смотрите на организацию впервые, полезно ориентироваться так:

- **Сервисы и прикладная логика** — репозитории с моделями, API и прикладными сценариями.
- **Инфраструктура и наблюдаемость** — репозитории с оркестрацией, маршрутизацией, алертами и эксплуатационными правилами.
- **Общие правила и связность** — мета-репозитории с регламентами, доступами и межрепозиторной координацией.

Мы сознательно держим инженерную правду рядом с кодом: актуальные контракты, ограничения, документы по запуску и рабочие инструкции живут в самих репозиториях.

<h2 align="center">Технологический контур</h2>

- **Backend / API:** Python, FastAPI, HTMX, Celery
- **ML / Data:** PyTorch, мультимодальные пайплайны, обработка речи, документов и изображений
- **Инфраструктура:** Docker, Terraform, Yandex Cloud, Redis, PostgreSQL, Object Storage
- **Наблюдаемость:** VictoriaMetrics, Grafana, Loki, Alertmanager, Gatus, GlitchTip
- **Инженерный контур:** GitHub Actions, self-hosted runners, единые стандарты, межрепозиторная база знаний

---

<h2 align="center">Что для нас важно</h2>

- **Проверяемость** — важные инженерные решения должны иметь наблюдаемые доказательства.
- **Прозрачность** — документы, ограничения и рабочие регламенты не прячутся вне репозиториев.
- **Надёжность** — инфраструктурные решения проходят через честные проверки, а не через оптимистичные предположения.
- **Локализация** — описательный инженерный текст мы ведём по-русски, без лишнего жаргона.
